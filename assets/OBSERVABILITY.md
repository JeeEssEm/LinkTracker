# PromQL
все запросы описаны в файле example_pql.txt

## RED-метрики
дэшборд с разбивкой по сервисам:
- scrapper
- bot
- ai agent service

Для всех метрик используется time series. Для errors выводится процент ошибок (4xx и 5xx).
Сам дэшборд лежит в infra/grafana/dashboards/default-dashboard.json

![пикча](assets/red.png)

## Бизнесовые метрики
Описание в ТЗ так себе (метрики из таблицы не очень маппятся на текстовое описание. Например, в таблице `command_duration_ms_total` <=> запросу в API. Потом же в тексте требуется время работы команды, по идее одно и то же, но вроде и разное) + непонятно, почему именно такие метрики (например, зачем вообще считать общее число выполненных команд)

# Подключенные метрики
- Количество ссылок на мониторинге
- Количество запросов к API Scrapper
- Время выполнения команд (поход в БД, обращение к соседним сервисам, к LLM-агентам)
- Количество команд в боте
- Количество отправленных уведомлений
